SIMPLE LIGHTING - website rebrand mockup (from kamslighting.com)
==================================================================

Open:  site\index.html   (double-click; works fully offline)
   or: Start Simple Website.bat  (double-click; runs a local server at
       http://localhost:8765 and opens the site; keep its window open)

To share: copy or zip the whole "site" folder (about 450 MB, mostly videos).
Keep the "assets" folder next to the .html files or the images will not load.

Pages: index (Home), products, product (sample series page: CL38E, with working
       type filters), model (sample model page: K-CL38E-207R-R2W), projects,
       downloads, news, videos, about, contact

What was changed
- Every "KAMS", "Kam's", "KAMS LED", "KAMS Lighting" in page text, titles,
  image alt text and SEO tags -> "SIMPLE" / "Simple".
- Company name -> "Simple Lighting Co. (H.K.) Limited".
- Email/website -> sales@simpleled.com / www.simpleled.com (placeholders).
- Header and footer logo -> "simple. LIGHTING" wordmark (placeholder logo).

Still showing the old brand (inside photos, not text)
- Catalogue cover images (the Kams logo is printed on the covers)
- Reception wall photo in "About" (KAMS sign on the wall)
- Product photos that have a Kams logo on the product or packaging
These need edited images from your designer.

Notes
- All images, styles, fonts and videos are stored locally in site\assets\simple\.
- This is a static snapshot for presentation. Search, login and language switch
  do not work; enquiry forms are not sent. On the model page, the data sheet
  buttons build a Simple-branded sheet (print / save as PDF) and Generate Quote
  Excel downloads a .csv quote. Every product links to the one
  sample series page, and every model to the one sample model page.
- raw\ holds the original rendered pages, used to rebuild site\.
